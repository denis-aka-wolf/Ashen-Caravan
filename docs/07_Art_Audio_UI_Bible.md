# 07. Арт, аудио и UI — библия стиля

**Версия:** 2.0 · **Статус:** на утверждение. Стиль — «уют посреди пустоши».

## 1. Визуальная идея

Пепельное небо и ржавая пустошь, но в центре — тёплый караван с гирляндами и огнями фар. Контраст холодного и тёплого создаёт уют и читаемость. Мультяшный стиль: плоские формы, мягкие контуры, без крови, оружия и тревожных образов (3.4.3, 8.3.6).

**Референсы по настроению (не копировать):** лёгкая техно-романтика, «путешествие на колёсах», мягкая мультяшность.

## 2. Палитра

Погодные темы prestige (цветовые фильтры поверх сцены): Пыль (тёплая серо-бежевая), Туман (холодная бело-серая), Ливень (синевато-серая), Закат (оранжево-розовая).

## 3. Типографика

| Назначение | Шрифт | Примечание |
|------------|-------|-----------|
| Заголовки | Russo One (или другой технический шрифт с кириллицей) | Лицензия OFL — проверить при подключении |
| Основной текст | Rubik | Кириллица + латиница |
| Числа | Rubik, tabular-nums | Чтобы цифры не «прыгали» |

Минимальный размер текста на мобильных — 14 px (логических), основных кнопок — 16 px+.

## 4. UI-компоненты

| Компонент | Спецификация |
|-----------|--------------|
| Кнопка | Мин. высота 48 px, радиус 12, состояния: normal / pressed / disabled / «можно купить» (пульс) |
| Карточка техники | Иконка, название, количество, цена, прогресс до вехи, доход/с |
| Нижние вкладки | 5 вкладок, иконки + подписи, активная подсвечена янтарём |
| Верхняя панель | Лом, доход/с, ЧР; числа с резервом ширины |
| Окна | Затемнение 60%, закрытие по тапу вне/крестику, не перекрывают sticky-баннер |
| RV-кнопка | Иконка «видео» + текст награды («Смотреть рекламу: ×2 лом»), янтарный акцент |

Принципы: одна рука, крупные зоны нажатия, никаких перекрытий текстов (1.10.3), интерфейс не обрезается при повороте (1.10.1).

## 5. Список ассетов v1.0

### Сцена
| Группа | Кол-во | Примечание |
|--------|--------|-----------|
| Параллакс-слои × 4 зоны | 4 × 3 слоя | Руины, равнина, шоссе у воды, перевал |
| Караван (Маяк + сцепка) | 1 набор | 2–3 апгрейда внешнего вида |
| Находки | 6 видов | Блик, мерцание |
| Грузовой дирижабль | 1 | Анимация полёта |
| Погодные фильтры | 4 | Шейдер/оверлей, а не отдельные арты |

### Техника (8 тиров)
По 1 спрайту + 2 визуальных состояния (до/после веха 100) → ~24 кадра.

### Персонажи
Искра (дрон), Гвоздь, Тётя Роза — портреты 3 эмоции каждый, 1 силуэт «Голос из рации» (радио-иконка).

### Иконки
~50: ресурсы, вкладки, достижения (30), таланты (12), настройки.

### Косметика за жетоны
6 предметов для v1.0: стартовый набор раскрасок «Маяка» и гирлянд. В дальнейших версиях ассортимент можно расширять сезонными и праздничными вариантами.

### VFX
Частицы искр, пыли, «золотая жила», вспышки находок, конфетти prestige.

### Нарратив
3 кадра пролога + 4 иллюстрации-«открытки» по зонам (опционально).

## 6. Аудио

### Музыка (2 трека, зацикленные)
1. «Дорога» — мягкая, медленная, акустическая гитара/синтезатор.
2. «Стоянка» — более тихая версия для окон/меню.

### Эффекты (~15)
Тап находки, покупка, веха, ошибка/недоступно, открытие зоны, prestige, награда, дирижабль, радио-помехи, клик UI, окно открыто/закрыто, жетон.

### Правила
- Громкость нормализована; музыка тише эффектов.
- Кнопка «звук» на главном экране (6.2).
- Пауза при сворачивании и рекламе (1.3, 4.7).
- Старт аудио — после первого жеста игрока (ограничение автозапуска в браузерах).
- Источники: стоковые библиотеки с коммерческой лицензией (сохранять чеки/лицензии) или заказ у композитора.

## 9. Промоматериалы (для карточки игры)

Актуальные размеры и ограничения — по форме черновика в консоли. Из требований платформы:

| Элемент | Правило |
|---------|---------|
| Иконка и обложка | Не скриншоты из игры (5.6); без рамок и скруглений (8.3.3); без элементов интерфейса платформы и системного UI (8.3.4) |
| Скриншоты | Реальный геймплей ≥ 70% изображения (5.1.1.2) |
| Видео | Реальный геймплей ≥ 70% длительности (5.1.1.3) |
| Тексты | Название идентично во всех материалах (5.1.3), уникально в каталоге (5.12) |
| Качество | Без артефактов сжатия, обрезанного текста (8.3.1) |

Концепт иконки: фара «Маяка» янтарным светом в пепельном небе, силуэт каравана; обложка — караван на дороге на закате.

## 10. Чеклист «безопасно для всех» (8.3.6)

- Нет крови, оружия, мёртвых тел.
- Нет символики конфликтов, политики, религии.
- Враждебных персонажей нет.
- Пепельное небо и руины — без «руин после бомбёжки» (избегать воронок, обгоревших жертв).
