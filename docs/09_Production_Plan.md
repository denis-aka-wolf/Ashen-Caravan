# 09. План производства

**Версия:** 2.0 · **Статус:** на утверждение. Оценки — для команды из допущения A1 (1 разработчик ≈ 25 ч/нед + внешний художник).

## 1. Роли

| Роль | Кто | Загрузка |
|------|-----|----------|
| Продюсер / геймдизайнер / разработчик | Вы | ≈ 25 ч/нед |
| Художник (2D, UI, анимации) | Внешний (фриланс) | по задачам |
| Звук | Сток + при необходимости заказ | 2 этапа |

## 3. Гейты (Go/No-Go)

| Гейт | Критерии |
|------|----------|
| **G1 — после M1** | Цикл «играть ещё минуту» работает: 5 внешних тестировщиков, ≥ 3 говорят, что вернулись бы; симуляция выдаёт 45–60 мин до 1-го перегона |
| **G2 — после M2** | Игра грузится ≤ 4 с; нет крашей за 30 мин; FTUE пройден ≥ 80% тестеров; иконка/название проверены на опросе |
| **G3 — после M3** | Весь контент играбелен; сохранение/восстановление проверено; remote-параметры применяются с fallback; лидерборд работает; игра без рекламы проходима; нет блокеров по `11` |
| **G4 — после M4** | Все обязательные пункты `11` зелёные на реальных устройствах; архив ≤ 20 МБ |
| **G5 — после M5** | Принята модерацией; метрики консоли подключены |

При провале гейта — сократить объём (см. разд. 6), а не продлевать срок.

## 5. Оценка арт-объёма (в единицах, цены — по рынку на момент найма)

| Блок | Объём |
|------|-------|
| Фоны/параллакс | 4 зоны × 3 слоя |
| Техника | 8 тиров × ~3 кадра |
| Караван + апгрейды | 1 набор |
| Персонажи | 3 портрета × 3 эмоции |
| Иконки | ~50 |
| UI-каркас | кнопки, панели, окна, вкладки |
| Промо | иконка, обложка, скриншоты, (опц.) ролик |

**Бюджет** = (часы художника × ставка) + (звуки/музыка: сток/заказ) + (лицензии шрифтов, если платные) + (оформление статуса для выплат) + (инструменты). Подставить ваши ставки: актуальные рыночные цифры в документ не закладывались, чтобы не вводить в заблуждение.

## 6. Резерв скоупа (что сокращать при отставании)

В порядке отказа:
1. Радио-записи: 16 → 8.
2. Достижения: 30 → 20.
3. Погодные темы: 4 → 2.
4. Зону 4 («Горный перевал») перенести в v1.1 (снять тиры 7–8, пересчитать `04`).

**Не режем:** FTUE, офлайн, локальное сохранение прогресса, базовый remote-конфиг, базовый лидерборд, стартовые 6 косметических предметов, prestige, пауза звука и рекламы, требования модерации. Дополнительные таблицы и сезоны лидербордов в v1.0 не входят.

## 8. Definition of Done

Задача завершена, если: работает на мобильном и десктопе; нет ошибок в консоли (6.4); тексты локализованы; не нарушает пункты `11`; удалённые параметры проверены на валидной и некорректной конфигурации; сохранение восстанавливается; есть событие аналитики (если применимо); обновлён документ.

## 9. Инструменты

## 10. Юридическое и финансовое

- До публикации: статус для выплат (самозанятый/ИП/юрлицо), реквизиты в консоли.
- Игры с инап-покупками: предварительное согласование с командой платформы.
- Лицензии на сторонние ассеты (шрифты, звуки) хранить.
- Это не юридическая консультация: уточнить детали у специалиста.
