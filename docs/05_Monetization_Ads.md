# 05. Монетизация и реклама

**Версия:** 2.0 · **Статус:** план для v1.0 (реклама) и v1.1 (инап-покупки)

## 1. Принципы

1. Игра проходима без просмотра рекламы и без покупок.
2. Rewarded — только по желанию игрока, с понятной наградой.
3. Interstitial — только в логических паузах.
4. Реклама и платежи — **только через SDK Яндекс Игр** (4.1, 1.4).
5. Награда за RV — бонус, но не условие продолжения игры (4.5.2).

## 2. Ограничения платформы (проверено по требованиям от 09.10.2026)

| Пункт | Что значит для нас |
|-------|--------------------|
| 1.12 | В игре должна быть подключена монетизация (реклама или покупки) либо явно указано в комментарии разработчика, что её нет |
| 1.16 | Нельзя имитировать рекламные блоки: свои «полноэкранные» блоки и кнопки RV запрещены |
| 4.1 | Реклама только через SDK; сторонних рекламодателей, статичных рекламных картинок и текстов нет |
| 4.2 | Прогресс сохраняется после перехода по рекламе и возврата |
| 4.3 | Ориентация рекламных блоков соответствует ориентации игры |
| 4.4 | Реклама не мешает игре, показывается в логических паузах; после Game Ready |
| 4.5 / 4.5.1 | Кнопка RV явно сообщает, что будет реклама и какая награда |
| 4.5.2 | Награда — дополнительный бонус, а не условие продолжения |
| 4.6 | Дополнительные блоки — только sticky-баннеры; кастомные RTB-баннеры запрещены |
| 4.7 | При показе полноэкранной рекламы пауза звука и игрового процесса |

## 3. Плейсменты rewarded (v1.0)

| ID | Где | Награда | Кулдаун | Примечание |
|----|-----|---------|---------|-----------|
| `rv_offline_x2` | Окно «Пока караван стоял» | ×2 офлайн-лом | — (раз на вход) | Главный плейсмент |
| `rv_boost` | Кнопка «Ускорение» на главном | ×2 доход на 4 мин | 10 мин | Подсветка при доступности |
| `rv_airship` | Кнопка «Вызвать дирижабль» | Гарантированный дирижабль | 3 мин | |
| `rv_daily_x2` | Ежедневный бонус | ×2 награда дня | раз в день | |
| `rv_skip_request` | Просьба попутчика | Пропуск просьбы с наградой в виде жетонов | по кулдауну просьбы | Опционально |

Подписи кнопок: «Смотреть рекламу: ×2 лом» (значок видео + текст награды).

## 4. Interstitial

| Правило | Значение (стартовое) |
|---------|----------------------|
| Первый показ | Не раньше 5 минут игры и не раньше окончания FTUE |
| Минимальный интервал | 120–180 с (флаг `adv_interval_sec`) |
| Допустимые моменты | После закрытия окна офлайн-дохода; после подтверждения «Нового перегона»; после выполнения просьбы; при возврате на главный экран из меню |
| Запрещено | Во время тапов по находкам, во время открытого окна покупок, сразу после RV (минимум 60 с «передышки»), при старте игры |
| Поведение | Пауза звука и логики (4.7), корректный возврат (4.2) |

## 5. Sticky-баннер

Включается и настраивается в консоли. Решение v1.0: **вкл. только в портрете на десктопе** (если не ломает вёрстку; проверить 1.10.1–1.10.3). Расположение не должно перекрывать нижние вкладки.

## 6. Инап-покупки (v1.1)

| Условие | Требование |
|---------|-----------|
| Платежи | Только SDK (1.4); цена в портальной валюте, определяется автоматически (1.13.2, 1.13.4) |
| Консумирование | Подключить метод консумирования (1.13.1) |
| Прогресс | Должен сохраняться на сервере и быть доступен с разных устройств (1.13.3) → предложение авторизации (1.2.1) |
| Согласование | До добавления покупок написать на games-partners@yandex-team.ru с названием и ID игры |
| Совпадение с консолью | Список товаров в игре = активные покупки в консоли (1.13.6) |

### Предлагаемые товары (гипотеза, цены — ступени из списка консоли)

| Товар | Тип | Идея |
|-------|-----|------|
| Без полноэкранной рекламы | Постоянный | Отключает interstitial (RV остаются по желанию) |
| Стартовый набор | Разовый | Жетоны + бесплатные 4 часа дохода + косметика |
| Постоянный ×2 доход | Постоянный | Баланс подбирать, чтобы не ломал prestige |
| Авто-сбор находок | Постоянный | Удобство для пассивных игроков |
| Косметика каравана | Консумируемая/постоянная | Раскраски «Маяка», гирлянды, значки |

## 7. Remote-флаги (SDK позволяет менять поведение без нового билда)

| Флаг | Назначение |
|------|-----------|
| `adv_first_delay_sec` | Задержка до первого interstitial |
| `adv_interval_sec` | Интервал между interstitial |
| `rv_boost_cooldown_sec` | Кулдаун буста |
| `rv_boost_mult` | Множитель буста (2…3) |
| `offline_cap_h`, `offline_eff` | Параметры офлайна |
| Флаги экономики | См. `04`, разд. 9.3 |

## 8. Модель дохода (шаблон, без выдуманных цифр)

```
ARPDAU = ( RV_views_per_DAU × eCPM_RV  +  IS_views_per_DAU × eCPM_IS ) / 1000
Revenue_month ≈ DAU_avg × ARPDAU × 30
```

Значения eCPM неизвестны и зависят от аудитории — брать из консоли после первых 2 недель. До этого — только чувствительность: «что будет при 1/2/3 просмотрах RV на DAU».

## 9. Выплаты и статус

- Единая лицензионная схема объединяет рекламу и инап-покупки; выплата — одним платежом.
- Вознаграждение при достижении порога выплачивается в течение 20 рабочих дней следующего месяца (по документации).
- Лицензионное соглашение: выплаты — с 18 лет; для РФ допустимы самозанятый, ИП, юрлицо. Оформить статус до публикации.

## 10. Антипаттерны (не делать)

- Блокирующие «стены» из рекламы.
- Принуждение к RV для основного прогресса.
- Кнопки RV без явной награды и обозначения.
- Скрытый показ рекламы по случайным тапам.
- Ссылки на внешние ресурсы (8.4.2, 8.4.4).
