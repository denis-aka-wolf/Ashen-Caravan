## 3. Проверенные факты и гипотезы

**Проверено по документации Яндекс Игр (редакция требований от 09.10.2026):**
требования к играм (разделы 1–5, 8), лимит 100 МБ в распакованном виде, `index.html` в корне архива, обязательность SDK и `LoadingAPI.ready()`, автоопределение языка через SDK, правила рекламы (4.x), срок модерации 3–5 рабочих дней, порог рейтинга 30, правило «10 минут контента либо мотивация перепроходить».

**Гипотезы (не бенчмарки платформы):** KPI (D1/D7, длина сессии), доля просмотров rewarded, eCPM, темп прогрессии, цены.

**Перепроверить перед стартом разработки и перед сдачей на модерацию:**
1. Названия методов SDK (серверное время, лидерборды, feedback, флаги) в актуальной документации.
2. Уникальность названия в каталоге (п. 5.12).
3. Лимиты на размер сохранений в SDK.
4. Размеры иконки, обложки и скриншотов — по форме черновика в консоли.
5. Условия лицензионного соглашения и выплат для вашего юридического статуса.

## 4. Как пользоваться пакетом

1. `01` и `03` — «что делаем». Утвердить первыми.
2. `04` — вынести в таблицу и прогнать симуляцию **до** кода экономики.
3. `06` + `11` — до первой строки кода заложить требования платформы в архитектуру.
4. `09` — сверять прогресс на гейтах (Go/No-Go).
5. Документы живые: при изменении решений обновлять версию и дату.

## 5. Глоссарий

| Термин | Значение |
|--------|----------|
| Idle / incremental | Игра, где ресурс копится автоматически, а игрок усиливает производство |
| Prestige | Добровольный сброс прогресса за постоянный бонус («Новый перегон») |
| RV | Rewarded video — реклама за вознаграждение по желанию игрока |
| Interstitial | Полноэкранная реклама в логической паузе |
| FTUE | First-time user experience — первые минуты игры |
| ARPDAU | Средний доход на активного пользователя в день |
| Лом | Основная валюта (запчасти и хлам, который собирают экипажи) |
| Чертежи (ЧР) | Валюта prestige |
| Жетоны | Редкая мягкая валюта за заказы и достижения |
