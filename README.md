# Пепельный караван — игровой прототип

Игровой вертикальный срез на серых блоках с механиками v1.0: 8 тиров техники, 4 зоны, находки, улучшения, просьбы, prestige, таланты, ежедневные награды, достижения, косметика, радио и офлайн-доход. Интеграции SDK Яндекс Игр, облачной синхронизации, глобального лидерборда и рекламы пока нет.

Порог 10 единиц предыдущего тира для открытия следующего — стартовое балансировочное допущение; параметры и контент прототипа задаются в `src/core/config.ts`.

Механики игры доступны через вкладки внизу экрана. В демонстрационном лидерборде отображается только локальный результат; внешние игроки и таблицы SDK не эмулируются. Удвоение офлайн-награды за рекламу, облачные сохранения и вызов дирижабля через rewarded-ad не работают без SDK.

## Требования

- Node.js 22.18 или новее
- npm 10 или новее

## Установка и запуск

```powershell
npm install
npm run dev
```

Откройте локальный адрес Vite, напечатанный в терминале.

## Проверки и production-сборка

```powershell
npm test
npm run build
npm run preview
```

Сборка создаётся в `dist/`. `npm run build` сначала выполняет строгую проверку TypeScript, затем собирает браузерную версию.

## Симуляция экономики

Симулятор использует то же ядро, что и игра, все 8 тиров и ограничение открытия по зонам. Базовый сценарий моделирует покупку генератора с минимальной окупаемостью и сбор одной находки через заданный интервал.

```powershell
npm run simulate
npm run simulate -- --hours 4 --tap-every 15
```

В отчёте выводятся времена достижения контрольных количеств техники, состав каравана, доход в конце периода и оценка четырёхчасового офлайн-дохода. Симулятор пока не моделирует случайные события, выполнение просьб, покупку улучшений и престиж; результаты — инструмент калибровки, а не гарантированный игровой темп.

## Структура

```text
src/
  core/       Чистая экономика, состояние, находки, офлайн, сохранение, симуляция
  scene/      Phaser-сцена дороги и находок
  ui/         DOM-интерфейс прототипа
  main.ts     Связка состояния, сцены, UI и localStorage
scripts/
  simulate-economy.ts
```

`src/core/` не импортирует Phaser или DOM и проверяется Vitest. Прогресс хранится локально в браузере и мигрирует со старого формата сохранения. Базовый офлайн — 4 часа с эффективностью 50%; таланты и улучшения могут поднять значения по игровым ограничениям. Числа пока используют `number`, поэтому прототип не рассчитан на экономику с астрономическими величинами idle-игры.
