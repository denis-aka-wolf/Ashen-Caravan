# Пепельный караван — прототип M1

Минимальный рабочий цикл на серых блоках: лом, три тира техники, находки, офлайн-доход и отдельная симуляция экономики. Интеграции SDK Яндекс Игр и финального арта пока нет.

Временное правило прототипа: тиры 2 и 3 открываются после покупки 10 единиц предыдущего тира. Порог — балансировочное допущение для M1, его можно менять в `src/core/config.ts`.

## Требования

- Node.js 22.18 или новее
- npm 10 или новее

## Установка и запуск

```powershell
npm install
npm run dev
```

Откройте локальный адрес Vite, напечатанный в терминале.

## Проверки и production-сборка

```powershell
npm test
npm run build
npm run preview
```

Сборка создаётся в `dist/`. `npm run build` сначала выполняет строгую проверку TypeScript, затем собирает браузерную версию.

## Симуляция экономики

Симулятор использует ту же логику тиров и дохода, что и игра. Базовый сценарий моделирует покупку наиболее выгодного доступного генератора и сбор одной находки каждые 10 секунд.

```powershell
npm run simulate
npm run simulate -- --hours 4 --tap-every 15
```

В отчёте выводятся времена достижения контрольных количеств техники, состав каравана, доход в конце периода и оценка четырёхчасового офлайн-дохода. Предположения симуляции — это инструмент калибровки, а не гарантированный игровой темп.

## Структура

```text
src/
  core/       Чистая экономика, состояние, находки, офлайн, сохранение, симуляция
  scene/      Phaser-сцена дороги и находок
  ui/         DOM-интерфейс прототипа
  main.ts     Связка состояния, сцены, UI и localStorage
scripts/
  simulate-economy.ts
```

`src/core/` не импортирует Phaser или DOM и проверяется Vitest. Прогресс хранится локально в браузере; офлайн начисляется по сохранённой временной метке с лимитом 4 часа и эффективностью 50%.
